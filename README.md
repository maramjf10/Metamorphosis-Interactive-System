# Metamorphosis-Interactive-System
Live Demo | [Metamorphosis](https://metamorphosis-sqde.onrender.com)

Interactive computer vision project – interactive 3D particle experience controlled by hand gestures.
Transforms 3D models into thousands of particles using a webcam and real-time hand tracking. You can control how these particles expand and reform.
This project combines Three.js, MediaPipe, and computer vision.

## Features

- **3D Particle Transformation:** Converts 3D models into thousands of particles.
- **Hand Tracking:** Uses the webcam to detect and track hand movements in real time.
- **Open Hand Gesture:** Expands the selected 3D model into a particle cloud.
- **Closed Fist Gesture:** Gradually reforms the particles into their original 3D shape.
- **Two-Hand Detection:** Detecting two hands simultaneously switches to the next 3D model.
- **Interactive Model Selection:** Models can also be selected using the on-screen interface.
- **Manual Controls:** Includes an expansion slider and keyboard controls.
- **Webcam Controls:** Users can turn hand tracking on or off.
